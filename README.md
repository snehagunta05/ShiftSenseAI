# ShiftSense AI

ShiftSense AI is an intelligent industrial shift handover and operational memory system.

It uses Hindsight as a long-term memory layer to store shift reports and retrieve relevant historical information when similar incidents occur.

## Main Features

- Shift report recording
- Industrial equipment information
- Temperature tracking
- Vibration tracking
- Pressure tracking
- Incident recording
- Corrective action recording
- Historical memory
- Incident analysis
- Similar incident retrieval
- Operational knowledge recall
- Demo scenario

## Technology

- Python
- Streamlit
- Hindsight
- Hindsight Python SDK
- python-dotenv
